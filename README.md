## ✨ Características

- **Gestão de Usuários:** Cadastro completo com documentos e CNH  
- **Catálogo de Veículos:** Controle de frota com categorias e status  
- **Sistema de Locação:** Reservas, cálculos automáticos e controle de prazos  
- **Processamento de Pagamentos:** Múltiplos métodos de pagamento  
- **API REST:** Endpoints completos para integração frontend  
- **Painel Admin:** Interface administrativa do Django  

---

## 🛠 Tecnologias

- **Backend:** Django 4.2 + Django REST Framework  
- **Banco de Dados:** SQLite (desenvolvimento) / PostgreSQL (produção)  
- **Autenticação:** Token-based + Session  
- **Documentação:** Auto-gerada via DRF
